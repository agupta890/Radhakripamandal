# Radha Kripa Mandal Sanstha — Project Instructions

## Project Overview

Build a professional, modern, responsive, and spiritually inspired website for:

**श्री राधा कृपा मंडल संस्था**

The website should be developed using the **MERN Stack**:

* **MongoDB** — Database
* **Express.js** — Backend API
* **React.js** — Frontend
* **Node.js** — Backend runtime

The complete website content should primarily be in **Hindi**, with clean Devanagari typography and a professional spiritual design.

---

# Design Theme

The website should have a peaceful and divine spiritual appearance inspired by:

* श्री राधा रानी
* भगवान श्री कृष्ण
* वृंदावन
* भक्ति
* मंदिर
* भारतीय आध्यात्मिक संस्कृति

The design should feel:

* Peaceful
* Divine
* Elegant
* Traditional but modern
* Professional
* Trustworthy
* Responsive

Avoid making the website look overly flashy or like a generic template.

Use subtle spiritual decorative elements such as:

* Lotus patterns
* Peacock feathers
* Flute-inspired elements
* Mandala patterns
* Temple silhouettes
* Soft floral decorations

Use these carefully and minimally.

# API Requirements

Create REST APIs.

## Events

* GET /api/events
* GET /api/events/:id
* POST /api/events
* PUT /api/events/:id
* DELETE /api/events/:id

## Blogs

* GET /api/blogs
* GET /api/blogs/:id
* POST /api/blogs
* PUT /api/blogs/:id
* DELETE /api/blogs/:id

## Gallery

* GET /api/gallery
* POST /api/gallery
* DELETE /api/gallery/:id

## Contact

* POST /api/contact
* GET /api/contact

## Authentication

* POST /api/auth/login
* POST /api/auth/register

Protect admin routes with JWT middleware.
